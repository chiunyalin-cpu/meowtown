# TOEIC POP! 750 💥

26 週衝刺多益 **750** 的線上課程，美式復古漫畫風。
參考 Speak AI 的「開口說」學習法，加上三款學習小遊戲，邊玩邊學、零壓力。
純網頁（PWA），手機、平板、電腦打開瀏覽器就能學，也可以「加入主畫面」當 App 用。

## 🎮 三款學習遊戲
| 遊戲 | 靈感 | 練什麼 |
|---|---|---|
| 🟩 每日猜字 WORDLE | Wordle | 每天一個多益單字，6 次機會猜 5 個字母，練拼字 |
| ☄️ 單字隕石 METEOR | 街機射擊／切水果 | 60 秒內點出掉落單字的中文，連擊加分，練字義反應 |
| 👾 文法魔王 BOSS FIGHT | RPG 打怪 | 答對 Part 5 題攻擊魔王，連續答對放大絕，練文法 |

不扣血、不倒扣。答錯的題目會自動進錯題本。

## 🌟 學習功能
- 🎙️ **AI 口說角色扮演**：24 個職場情境，對麥克風回答，即時評分並示範說法
- 💬 **AI 自由聊天**：吉祥物 Bubbo 陪你聊天並用中文修正句子（需自備 Anthropic API Key，選填）
- 🃏 **單字卡**：240 個多益高頻字，記憶曲線複習
- 🎧 **聽力 Part 2**、✏️ **文法 Part 5**、🔁 **跟讀**、📝 **迷你模擬考**
- ⭐ **經驗值與等級**、🏆 **14 張貼紙收集**、🔥 **連勝（每週可休息 1 天不斷連勝）**

## 建議瀏覽器
語音辨識需要 **Chrome**（電腦／Android）或 **Safari**（iPhone／iPad），並允許麥克風。不支援時可以打字作答。

## 自己修改內容
