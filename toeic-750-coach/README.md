# 喵町英語社 🐾

> 社員募集中！每天一點點・26 週衝多益 750

把多益學習做成手機遊戲的線上社團：主角是機器人社長貓「餅乾」。電腦、平板、手機都能用（PWA，可加入主畫面）。

## 玩法
- **今日任務**：單字卡、AI 口說、聽力、文法、跟讀。完成 1 項就算過關，每項都能拿「罐罐」。
- **單字卡**：記憶曲線複習；學過的字會輪流出「聽音拼字」「選中文意思」「例句填空」。
- **聽力**：Part 2 問答，以及 Part 3/4 對話與獨白（男女兩種聲音）。
- **閱讀**：Part 5 文法題（有文法標籤、每個選項的對錯說明、「再練一題同類型」），Part 6/7 短文填空與閱讀。
- **昭和扭蛋機**：30 罐罐轉一次，約 50 種獎品（帽子、髮飾、耳機、披風、翅膀、書包、各色鏡片、稱號、貼紙），每個月還有「本月限定」。新社員送 30 罐罐。也能用 20 罐罐買「連勝保護卡」（最多 2 張，連勝要斷時自動使用）。
- **每週挑戰**：每週一換一個挑戰（例如猜中 3 次每日猜字），完成拿罐罐和限定貼紙。
- **好友**：登入後用 6 碼好友代碼互加，看好友排行榜、一起完成每週合作挑戰。
- **26 週冒險地圖**：一週一關，第 6、12、18、24 週是魔王週。
- **遊戲中心**：每日猜字、單字隕石、文法魔王、模擬考（迷你版，或約 100 題、60 分鐘的半套模擬考，分別估算聽力和閱讀分數）。
- **錯題本**：依文法分類練習，也能列印或存成 PDF。

## 題量
第 1～24 週每週都有：

| 題型 | 每週 | 24 週合計 |
|---|---|---|
| 單字（附例句與中文翻譯） | 40 個 | 958 個不重複單字 |
| Part 2 問答 | 10 題 | 240 題 |
| Part 3/4 對話・獨白 | 2 組（各 3 題） | 48 組、144 題 |
| Part 5 文法（附標籤與選項解析） | 20 題 | 480 題 |
| Part 6/7 短文 | 1 篇（3–4 題） | 24 篇 |

第 25、26 週是衝刺週，會從前面所有週的題庫抽題。新增或修改題目後，可以執行 `python3 tools/check_content.py` 檢查題數、翻譯、單字重複和答案範圍。
- **社員證**：等級、成就、統計、排行榜（需開啟雲端）。

## 檔案
| 檔案 | 內容 |
|---|---|
| `index.html` / `style.css` | 介面（依 `design/v6` 風格規範） |
| `app.js` | 主程式 |
| `data.js` | 課程內容、扭蛋獎品 |
| `trans.js` | 英文句子的中文翻譯 |
| `tools/check_content.py` | 題庫檢查腳本（不用上傳） |
| `mascot.js` / `icons.js` | 主角貓與圖示 |
| `firebase-config.js` | **填入 Firebase 設定的地方** |
| `firebase.js` / `firestore.rules` | 雲端登入、同步、排行榜與安全規則 |

## 開啟雲端同步
1. 在 Firebase 建立專案，開啟 Authentication（Google）與 Firestore。
2. 把網頁應用程式的 `firebaseConfig` 貼進 `firebase-config.js`。
3. 把 `firestore.rules` 的內容貼到 Firestore › 規則，按發布。
4. 在 Authentication › 設定 › 授權網域加入你的 GitHub Pages 網域。
